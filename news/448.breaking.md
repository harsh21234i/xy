This PR proposes limiting prebuilt native wheels to Linux glibc x86-64, macOS
arm64, and Windows x64, the targets that pass native install and kernel smoke
checks on matching hosted runners. The reduction requires maintainer sign-off
before merge. If approved, Linux glibc aarch64 and armv7, all musllinux targets,
macOS x86-64, and Windows x86 and arm64 will require a local Rust toolchain until
runtime verification is added. The Pyodide 314 PyEmscripten wheel remains a
separate runtime-verified release artifact.
